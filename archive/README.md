# Archive

This directory keeps historical stage-specific assets that are no longer part of
the recommended slim FDM-MPPI pipeline.

- `tools/`: Stage 5 / Stage 6 experiment, plotting, and profiling scripts.
- `figures/`: Published historical Stage 5-E and Stage 6 figure artifacts.
- `tables/`: Published historical Stage 5-E and Stage 6 table artifacts.
- `configs/`: Reserved for legacy configuration snapshots when old configs are retired.

The supported day-to-day entry point is:

```bash
python3 tools/fdm_mppi.py --help
```
